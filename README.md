# TALYS Nuclear Reaction Cross Section Simulations

This repository contains simulation workflows and cross-section calculations performed using TALYS-2.2 for proton-induced nuclear reactions.

## Structure
* `inputs/`: Input parameters configuration (`talys.inp`)
* `scripts/`: Execution scripts (`run_simulation.sh`)
* `latex/`: PGFPlots source files for vector graphics rendering

## Evaluated Reactions
* $^{89}\text{Y}(p,x)^{89}\text{Zr}$ (Peak: 13 MeV, 879.38 mb)
* $^{89}\text{Y}(p,x)^{90}\text{Zr}$ (Peak: 8 MeV, 3.07 mb)
* $^{86}\text{Sr}(p,x)^{86}\text{Y}$ (Peak: 14 MeV, 873.01 mb)
